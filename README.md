# Roxie

A lightweight local terminal AI assistant powered by Ollama.

Roxie combines local AI with semantic conversation memory, tool calling, web search, timers, and Obsidian integration — all from a clean terminal interface.

## Features

- Local AI using Ollama
- Semantic memory with ChromaDB
- Customizable personality
- Tool calling
- Web search
- System information
- File reading and directory listing
- Countdown timers
- Current date and time
- Obsidian note integration
- Lightweight terminal interface
- Local-first design

## Requirements

- Python 3.10+
- Ollama
- ChromaDB
- `qwen2.5:3b-instruct`
- `nomic-embed-text`
